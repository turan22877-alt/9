# Лабораторная работа №9: Вложенные циклы
Дисциплина: Основы программирования и алгоритмизации (Язык Си / Visual Studio)

## Содержание работы
- **Задание 1 (9/1.c)**: Вложенные циклы. Печать числовой сетки / матрицы чисел по индивидуальному варианту.
- **Задание 2 (2/2.c)**: Разложение произвольного длинного числа на цифры. Подсчет повторений последней цифры в числе с организацией диалога повторного запуска (do-while).
- **Задание 3 (3/3.c)**: Рисование геометрической фигуры (пересекающиеся квадраты с пустой областью пересечения) заданным пользователем символом и масштабируемыми размерами.
